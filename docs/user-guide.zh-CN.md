# Waystone 完整使用手册

适用版本：**0.6.2**。适合小团队的项目负责人、开发者和服务管理员。普通成员只需自己的账号、项目邀请和一个 Agent，不需要登录服务器。

本手册先讲怎么协作，再提供可选的命令行操作。示例项目为“官网改版”；`https://memory.example.com`、`/absolute/path/to/repo`、`<project-id>` 等都需要换成实际值，服务地址带端口时必须保留。

## 先看这个流程

**负责人创建项目 → 邀请成员 → 成员连接并授权 Agent → 选择原项目 → 开始前查询 → 确认后保存 → 收尾时交接。**

Waystone 保存的是团队已经确认、值得后续复用的项目事实，例如架构决定、协作规范、资料位置和任务进度。聊天记录不会自动全部上传，创建项目也不会自动上传仓库。

日常记住三句话即可：

| 时机 | 对 Agent 说 |
|---|---|
| 开始或继续任务 | “先查这个项目的相关记忆，核对来源和适用范围，再继续。” |
| 确认一个结论 | “把刚确认的结论整理成候选记忆，给我确认后再保存。” |
| 换人、换设备或结束一天 | “整理进度、已验证结果和下一步，准备一条交接记忆给我确认。” |

## 账号与权限

每个人使用自己的账号。**登录账号、授权 Agent、加入项目是三个不同步骤**：账号登录成功不代表已经加入某个项目，连接器授权也不会自动创建项目。

| 操作 | 所有者 owner | 协作者 collaborator | 只读成员 reader |
|---|---|---|---|
| 查询有效记忆、查看项目记录 | 可以 | 可以 | 可以 |
| 发布新记忆、提交修订提案 | 可以 | 可以 | 不可以 |
| 采纳、重新提交或拒绝冲突提案 | 可以 | 不可以 | 不可以 |
| 邀请、移除成员、归档项目 | 可以 | 不可以 | 不可以 |
| 重试索引失败项 | 可以 | 可以 | 不可以 |
| 全量核对和重建索引 | 可以 | 不可以 | 不可以 |

项目创建人成为该项目的所有者。服务管理员负责部署和维护；项目所有者负责该项目的成员与知识审核。每个项目单独管理成员，加入一个项目不代表能访问其他项目。

撤回有单独规则：仍是项目成员的作者可以撤回自己发布的记录，所有者可以撤回项目内任意记录。当前版本不提供项目所有者转让或增设所有者的常规入口。

## 初次接入

### 推荐方式：远程 MCP

适用于支持远程连接的 Claude 客户端和 Codex。无需安装 Waystone、Python 或 uv；管理员需要已经启用远程连接器。

1. 向负责人取得服务地址和项目邀请。新成员先打开邀请链接，在浏览器注册或使用已有账号接受邀请。
2. 添加 `<服务地址>/mcp` 连接器，在浏览器授权自己刚刚发起的连接。
3. 让 Agent 列出已加入的项目，选择正确项目，再查询一条相关问题验证连接。

Claude 网页或桌面端通过连接器设置添加 URL。Claude Code 可执行：

```bash
claude mcp add --transport http --scope user waystone https://memory.example.com/mcp
```

然后在 Claude Code 内输入 `/mcp` 完成授权。Codex 可执行：

```bash
codex mcp add waystone --url https://memory.example.com/mcp
codex mcp login waystone
```

已有相同连接时直接复用。密码由你在浏览器填写；不要让 Agent 获取密码或复制授权令牌。远程模式每次工具调用使用项目 ID，不需要在本机生成项目绑定文件。

### 需要本地功能时：CLI 和 Skill

Pi、DSH，以及需要创建项目、邀请成员、本地文件预览或绑定仓库的用户，使用[本地安装流程](install.md#local-setup)。这些步骤可以交给 Agent 执行。

```bash
uv tool install "git+https://github.com/hb407033/waystone@v0.6.2"
waystone login --server https://memory.example.com
```

登录会打开设备授权页，请保持发起登录的进程运行，核对设备并在浏览器授权。CLI 登录和远程 MCP 授权各自独立；使用远程 MCP 的普通成员不必额外完成 CLI 登录。

安装 Skill 后可以使用这些入口，也可以直接用自然语言：

| 客户端 | 入口示例 |
|---|---|
| Claude Code | `/waystone recall 登录方案` |
| Codex | `$waystone recall 登录方案` 或选择 Skill |
| Pi | `/skill:waystone recall 登录方案`；可选配置 `/waystone` 快捷入口 |
| DSH | 通过客户端提供的 Skill 入口调用；也可让 Agent 使用 CLI |

仅配置了 MCP 并不等于安装了斜杠命令；快捷入口来自 Skill 或客户端提示模板。远程 MCP 本身已提供使用指导。

## 项目负责人的操作

### 创建一次项目

对有本地执行能力的 Agent 说：

> 请在当前目录配置“官网改版”项目记忆。先列出我已有的项目；如有同名项目，让我选择绑定还是另建。新建或绑定时不要上传任何文件。

对应的本地操作是：

```bash
waystone projects
# 确认确实需要新建后：
waystone --directory /absolute/path/to/repo init "官网改版"
```

如果项目已经存在，应使用它的真实 ID 绑定：

```bash
waystone --directory /absolute/path/to/repo bind <project-id>
waystone --directory /absolute/path/to/repo status
```

本地绑定文件 `.waystone.json` 保存项目 ID、名称和服务地址，可以提交到项目仓库。它不包含凭据，也不能授予成员权限。目录或其上级已经有正确绑定时直接复用。

### 邀请协作者或只读成员

```bash
# 默认邀请为协作者：
waystone --directory /absolute/path/to/repo invite colleague@example.com

# 邀请只读成员：
waystone --directory /absolute/path/to/repo invite reviewer@example.com --role reader
```

把命令返回的邀请链接、服务地址和本手册发给受邀者。**生成邀请链接不会自动发送邮件。**

邀请绑定指定邮箱、一次使用，CLI 默认有效期为 24 小时。过期、已使用或邮箱不匹配时，负责人核对后重新生成邀请。已有账号的成员使用自己的账号接受邀请，无需注册第二个账号。

### 导入已有项目资料

推荐对 Agent 说：

> 只读取我指定的 README.md 和 docs/architecture.md，提炼值得团队复用的已确认事实。按独立事实列出候选、主题、来源和适用范围，给我审核；不要直接上传全文。

需要离线预览文件时：

```bash
waystone --directory /absolute/path/to/repo import README.md --preview-only
```

预览不会上传，也不需要登录。当前预览会分块，这些原始块不应直接作为最终知识发布；让 Agent 提炼后，经确认逐条保存。原生 Agent 记忆目录、全部聊天记录和整个仓库不属于默认导入范围。

## 团队成员的操作

1. 用邀请指定的邮箱接受邀请，完成自己的账号准备；新账号密码至少 12 位。
2. 在自己的设备和 Agent 中完成连接授权。
3. 对 Agent 说：“列出我的项目，我要加入的是‘官网改版’，请让我核对项目 ID。”
4. 选择负责人已经创建的项目，再查询项目的决定和当前交接。

本地工作目录需要绑定时，先 `waystone projects`，再 `waystone --directory /absolute/path/to/repo bind <project-id>`。远程模式直接选定项目 ID 即可。

**加入项目不是重新创建同名项目。** 不同项目即使名称相同，也有不同 ID，成员和记录不会自动共享。

只读成员可以检索和查看记录；需要提交知识时，请负责人安排适当权限。当前 CLI 不提供直接修改成员角色的命令，不要把重复邀请当成自动升级权限的办法。

## 日常查询与保存

### 查询：先确定项目和适用范围

例如：

> 请查询“官网改版”项目里关于登录模块的已确认决定，说明来源、适用环境和分支。有待处理提案或未注明范围的记录，请单独指出。

已知要查询生产环境时：

> 请查询适用于 prod 环境、main 分支的部署约定。未注明适用范围的资料只能作为待核实参考。

可选 CLI：

```bash
waystone --directory /absolute/path/to/repo recall "登录模块有哪些已确认的决定？"
waystone --directory /absolute/path/to/repo --environment prod --branch main recall "部署约定"
```

全局参数如 `--directory`、`--environment`、`--branch` 放在操作命令之前。

检索不是记录全集。没有命中时可以让 Agent 分页查看记录、换一种问法，核对是否尚未索引或已经过期，不要直接得出“项目没有相关事实”。

### 保存：一条记忆一个事实

先让 Agent 展示候选，再确认要保存哪些：

> 把刚刚拍板的数据库选型准备为一条 decision；主题沿用已有数据库选型主题，标明讨论来源和已核实版本，先给我看正文。

你可以回复“保存这条”或“只保存第 1、3 条”。没有明确确认就不发布。团队可以要求任务收尾时主动整理候选，但这不等于允许自动上传。

| 类型 kind | 适合保存 | 例子 |
|---|---|---|
| `decision` | 已拍板的决定 | 某个业务项目选择的数据库或认证方案 |
| `convention` | 团队约定和规范 | 命名约定、提交规范、接口约定 |
| `background` | 项目背景、资料位置、数字口径 | 设计文档位置、某项指标的定义 |
| `handoff` | 进度、证据、待办与下一步 | 本轮已完成工作及未完成验收 |

Agent 还应填写：

| 信息 | 用途 |
|---|---|
| `topic` | 稳定主题，例如 `storage/database/engine`，同一事项修订时复用，不带临时序号 |
| `source` | 结论来自哪份文档、代码或已确认讨论 |
| `environment` | 适用环境，例如 prod / dev；未知留空 |
| `branch` | 结论适用的分支；不要把证据所在分支误当成适用分支 |
| `source_version` | 实际核实的提交号或文档版本；未知留空 |

留空意味着没有注明，不意味着适用于所有环境。不要保存未经确认的猜测、个人闲聊、密码、令牌或密钥；自动凭据检测只能辅助检查。

### 保存后的结果

| 返回状态 | 含义与下一步 |
|---|---|
| `active` | 记录当前有效；如果同时是 `index_status=ready`，已进入检索索引 |
| `proposed` | 与同主题、同环境、同分支的记录形成修订提案，需所有者审核 |
| `index_status=pending` | 数据已保存，但索引尚未就绪；不要误认为保存失败而重复提交，重试索引即可 |

首次保存新主题可以直接成为有效记录；不是每条新记录都要所有者额外批准。同一主题的变更会走提案，不能自动覆盖旧结论。

纯 CLI 的 `save` 固定保存为 decision，`handoff` 固定保存为 handoff；其他类型使用 MCP。CLI 会分块处理文件，建议候选文件只含一个事实、没有空行且不超过 400 字。更复杂的资料交给 Agent 提炼后逐条发布。

## 交接和换设备

### 结束一轮任务

对 Agent 说：

> 请整理一条交接候选，包含当前目标、已完成内容、验证结果、未完成项、相关文件或提交和下一步。先让我审核，再以 handoff 保存。

handoff 默认 7 天后不再参与有效记忆召回，历史仍保留。过期后仍有价值的交接，需要重新核对、确认保存，生成新的记录和有效期；长期决定应单独用 decision 或 convention 保存。

### 换电脑、换 Agent 或交给同事

新设备完成自己的授权，再选择相同项目 ID，然后说：

> 请先读取这个项目的有效交接和与当前任务有关的决定，核对代码与来源版本，告诉我从哪里继续。

本地仓库已有 `.waystone.json` 时仍需自己登录并拥有成员权限；不用复制别人的 session 文件。换 Agent 不会自动迁移尚未发布的聊天内容，所以交接前应把重要进度整理并确认保存。

### 退出或撤销连接

`waystone logout` 只退出当前 CLI 会话，不会撤销其他设备或远程连接器的授权。

查看并撤销远程应用授权，可通过已登录的本地 CLI：

```bash
waystone connections
waystone disconnect <client-id>
```

`<client-id>` 从列表中选取；撤销前核对应用。移除成员则只取消其对指定项目的访问，不会删除该人的账号、其他项目权限或已发布记录；误发内容需要单独撤回。

## 冲突修订与撤回

### 正常修订

1. Agent 查询已有记录，复用同一主题和适用范围。
2. 你确认新内容后发布，系统返回 proposed，旧记录继续有效。
3. 所有者对比正文、来源、环境、分支和版本，选择采纳或拒绝。
4. 采纳后新记录生效，旧记录成为 superseded，历史保留。

时间较新不代表内容一定正确。系统主要识别**同主题、同环境、同分支**的版本竞争，不能保证自动识别不同主题之间的语义矛盾。

### 多人同时修订

例如 B、C 都基于 A 提案，B 已被采纳，而 C 还想继续提交：所有者先对比 C 与当前的 B，确认后将 C rebase 到 B，再单独确认是否采纳。**rebase 本身不使 C 生效。**

遇到 409“版本已变化”，先重新读取当前状态，不强行重复覆盖。reject 为终态；想重新考虑被拒绝内容时，核实后重新发布。当前版本被撤回或过期、已没有有效版本时，所有者核对后可采纳提案：MCP 的 `expected_id` 留空，CLI 省略 `--expected`；应让 Agent 按真实状态处理。

### 撤回误发内容

告诉 Agent 要撤回哪条记录，先展示记录 ID 和范围，再确认撤回。所有者可撤回任意项目记录，作者可以撤回自己的记录。

撤回会抹除正文并删除对应向量，**不可恢复**，但保留主题、作者、时间和审计。返回 `purge_pending` 时，需要重试同一条撤回或请管理员核对；不要当作已经彻底删除。

已有备份和 Mem0 历史可能仍含原文，按实际保留策略轮换或由管理员核对清理；默认备份脚本保留 28 天。若误发凭据，应先撤销或轮换凭据，撤回记忆不能代替凭据失效处理。

## 与原生记忆如何分工

| 内容 | 放在哪里 |
|---|---|
| 项目正式约束、工作规则 | 仓库中的 AGENTS.md / CLAUDE.md 等规则文件 |
| 个人偏好、本机经验 | Agent 原生记忆 |
| 团队共享且有来源的项目事实 | Waystone |
| 未经确认的讨论和临时探索 | 当前任务上下文，先不发布 |

Waystone 不改写、扫描或双向同步原生记忆。召回内容只是参考资料，不会自动获得高于用户要求、项目规则和工具权限的优先级。

发生矛盾时，先核对是不是同一项目、环境和分支，再核实代码及来源。可以验证的事实直接验证；无法确定的决定展示双方依据，让负责人选择。不要按时间戳自动裁决，也不要自动改写原生记忆来“保持一致”。

## 常见问题

| 情况 | 处理方式 |
|---|---|
| 已登录，但列表没有目标项目 | 核对账号邮箱，接受邀请；负责人确认邀请是否过期以及是否已加入。不要新建同名项目代替加入 |
| 401、需要重新授权 | 远程模式重新授权连接器；CLI 模式重新运行 `waystone login --server <服务地址>` |
| 403、没有项目权限 | 核对项目 ID 和成员角色；新绑定文件不能绕过权限，联系项目所有者 |
| 邀请无效、过期、邮箱不匹配 | 使用受邀邮箱；负责人重新生成邀请。邀请默认 24 小时、一次使用 |
| 设备授权超时 | CLI 设备码 10 分钟有效，重新发起登录并使用新链接；保持等待进程运行 |
| 看不到 MCP 工具或斜杠命令 | 核对连接授权和客户端是否已加载配置；Skill 和 MCP 分别验证，必要时重新打开客户端 |
| 远程模式没有创建项目或邀请工具 | 这是当前能力边界，使用本地 CLI 或请项目所有者操作 |
| 当前目录尚未绑定项目 | 本地模式先列项目再绑定；远程模式只需要正确 project_id |
| 项目服务地址与本机登录配置不同 | 核对服务地址、端口和绑定，登录正确服务器；不要修改地址来绕过校验 |
| 保存后搜索不到 | 核对 active / proposed、有效期、环境和分支，以及 index_status；分页查看记录并按需修复索引 |
| 503、向量检索暂不可用 | 请管理员检查 `/ready` 与 Mem0；仍可分页查看 SQL 记录，不能据此判断记忆丢失 |
| 写请求超时、结果未确认 | 先查看记录确认是否已经保存，不直接重复发布或再次做破坏性操作 |
| 400、内容疑似包含凭据 | 移除敏感内容后重新审核，不绕过检测 |
| 409、项目已归档 | 项目已停止新增和改写，查询历史仍可用；联系所有者，当前 CLI 没有取消归档入口 |
| 忘记密码或想集中撤销所有 CLI 会话 | 当前没有自助密码修改和全局 CLI 会话管理入口，联系服务管理员处理 |

## 管理员维护

普通成员可以跳过本节。部署、备份和恢复的具体步骤见[运维指南](operations.md)。

- 使用 `/health` 检查进程存活，使用 `/ready` 检查真实检索依赖；仅有 health 正常不代表检索可用。
- 主服务器按默认脚本每 6 小时备份、每 5 分钟检查、每月隔离恢复验证。需要异地保障时，配置独立节点每 5 分钟同步并核对完整性；这些任务不应依赖个人电脑。
- 邮件告警需单独配置发信授权并验证测试邮件和故障/恢复通知；存在监测日志不等于邮件已送达。
- 索引失败可由所有者或协作者重试；向量丢失或恢复数据库后，由所有者全量核对。`reindex` 和记录列表都可能分页，必须继续传 `next_cursor`，直到为空，并确认 `pending=0`。
- 成员离开项目时由所有者核对成员 ID 后移除。归档会冻结项目新增和改写，保留查询历史及必要的索引修复；不要把归档当作退出登录。
- 当前是单实例部署，支持小团队受控使用；不提供自动故障接管、跨主题语义矛盾识别或完整的账号管理界面。

## 常用命令速查

以下均由本地已安装并登录的 CLI 执行；需要确认的写操作会提示输入 `yes`。替换真实路径和 ID，不要原样复制尖括号占位符。

| 用途 | 命令 |
|---|---|
| 查看已加入项目 | `waystone projects` |
| 查看目录绑定 | `waystone --directory /absolute/path/to/repo status` |
| 绑定已加入项目 | `waystone --directory /absolute/path/to/repo bind <project-id>` |
| 查询 | `waystone --directory /absolute/path/to/repo recall "问题"` |
| 查看一页记录 | `waystone --directory /absolute/path/to/repo entries --limit 50` |
| 查看下一页 | `waystone --directory /absolute/path/to/repo entries --limit 50 --cursor <next-cursor>` |
| 保存单条决定 | `waystone --directory /absolute/path/to/repo save <topic> --file <候选文件> --source <来源>` |
| 保存交接 | `waystone --directory /absolute/path/to/repo handoff <topic> --file <候选文件> --source <来源>` |
| 接受提案 | `waystone --directory /absolute/path/to/repo resolve <entry-id> --expected <当前有效记录-id>` |
| 重新提交提案 | `waystone --directory /absolute/path/to/repo rebase <entry-id> --expected <当前有效记录-id>` |
| 拒绝提案 | `waystone --directory /absolute/path/to/repo reject <entry-id>` |
| 撤回记录 | `waystone --directory /absolute/path/to/repo retract <entry-id>` |
| 重试索引失败项 | `waystone --directory /absolute/path/to/repo reindex`，按返回游标继续 |
| 全量核对索引（所有者） | `waystone --directory /absolute/path/to/repo reindex --full`，按返回游标继续 |
| 查看成员 | `waystone --directory /absolute/path/to/repo members` |
| 移除成员（所有者） | `waystone --directory /absolute/path/to/repo remove-member <user-id>` |
| 查看审计（所有者） | `waystone --directory /absolute/path/to/repo audit` |
| 查看远程授权 | `waystone connections` |
| 撤销远程授权 | `waystone disconnect <client-id>` |

日常优先使用自然语言，Agent 根据 MCP 或 CLI 执行。**查询前确定项目，发布前确认内容，冲突交给所有者，交接后再换人或换设备。**
